# Hi, I'm Nyxnet

I make small tools, run a homelab and learn by building things. Right now that mostly means Oxipod, an app for old iPods, and teaching myself Rust while I write it.

## What I'm working on

**[Oxipod](https://github.com/nyxn3t/Oxipod)** puts music on your old iPod from Linux. I wanted to use my iPod nano again and there's no good way to do that on Linux anymore, so I made one. You plug in the iPod, drop some music on the window, and that's it. It converts what the iPod can't play, adds the covers, makes playlists, backs up the iPod and copies songs back to your computer.

<p align="center">
  <img src="https://raw.githubusercontent.com/nyxn3t/Oxipod/main/data/screenshots/songs.png" width="340" alt="The songs on an iPod nano, shown in Oxipod">
</p>

It's written in Rust with GTK4 and libadwaita, and it comes as a Flatpak:

```
flatpak remote-add --user --if-not-exists oxipod https://nyxn3t.github.io/Oxipod/oxipod.flatpakrepo
flatpak install --user oxipod io.github.nyxn3t.Oxipod
```

Rust is new to me, so the code has a lot of comments that explain what's going on. If you have an iPod, I'd love to hear [how it works on yours](https://github.com/nyxn3t/Oxipod/discussions/1).
